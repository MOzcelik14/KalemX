# KalemX 0.2.0 beta

- İlk sürümde kullanıcı tarafından doğrulanan X11 ekran çizim altyapısı.
- Kalem, fosforlu kalem, alfa silgisi ve çizgi/ok/dikdörtgen/elips araçları.
- Geri al, yinele ve bütün tuvali tek hamlede temizleme.
- Şeffaf PNG ve yeniden açılabilir .kalemx proje dosyası.
- Deneysel native Wayland Layer Shell arka ucu (KDE/wlroots compositor'ları).
- DEB ve Python paketleri, CI ve sürüm etiketleriyle GitHub Releases.

**Bilinen sınırlar:** GNOME Wayland desteklenmiyor; birinci ekran;
Wayland'da proje açma için --open kullan; gerçek compositor testleri sürüyor.
